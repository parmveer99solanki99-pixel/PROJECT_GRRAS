# 📊 PROJECT_GRRAS

A collection of **Data Science, Machine Learning, Data Analysis, and Python projects** developed during my practical learning and industrial training journey with **GRRAS Solutions**.

The repository focuses on applying Python and Machine Learning concepts to real-world datasets, including **semiconductor market analysis and COVID-19 data analysis**.

---

## 🚀 Projects Included

### 1. 🤖 AI Semiconductor Market Model

**Notebook:** `AI_SemiConductor_Model.ipynb`

This project analyzes semiconductor market data and applies Machine Learning techniques to identify patterns and build a predictive model.

#### Key Activities

* Data loading and preprocessing
* Data cleaning
* Exploratory Data Analysis (EDA)
* Feature selection and preparation
* Data visualization
* Machine Learning model training
* Model evaluation
* Saving the trained model using Joblib

#### Dataset

`ai_chip_market.csv`

The dataset contains semiconductor/AI chip market-related information used for analysis and model development.

#### Trained Model

`AI_Semiconductor_model.joblib`

The trained Machine Learning model is saved using **Joblib** so that it can be reused without training the model from scratch.

---

### 2. 🦠 COVID-19 Data Analysis

**Notebook:** `Covid_19.ipynb`

This project performs exploratory analysis of COVID-19-related data.

#### Key Activities

* Dataset loading
* Data cleaning
* Data preprocessing
* Exploratory Data Analysis
* Statistical analysis
* Data visualization
* Understanding trends and patterns

#### Dataset

`covid_19.csv`

---

### 3. 📚 Library Management System

**Python File:** `Library_Manage.py`

A Python-based Library Management project demonstrating programming fundamentals and practical file/data management concepts.

## ▶️ How to Run the Projects

### Step 1: Clone the Repository

```bash
git clone https://github.com/parmveer99solanki99-pixel/PROJECT_GRRAS.git
```

### Step 2: Navigate to the Project

```bash
cd PROJECT_GRRAS
```

### Step 3: Install Required Libraries

```bash
pip install numpy pandas matplotlib seaborn scikit-learn joblib jupyter
```

### Step 4: Start Jupyter Notebook

```bash
jupyter notebook
```

### Step 5: Open a Notebook

For the semiconductor project:

```text
AI_SemiConductor_Model.ipynb
```

For COVID-19 analysis:

```text
Covid_19.ipynb
```

Run the notebook cells sequentially to reproduce the analysis.
